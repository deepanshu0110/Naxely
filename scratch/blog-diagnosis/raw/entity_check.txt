# Naxely

> AI-powered PDF report generator. Turn CSV files and Google Sheets into branded, professional PDF reports with AI-written insights, charts, and tables.

Naxely is a SaaS platform that lets you upload a CSV file or connect a Google Sheet, configure custom branding (your logo, colors, fonts), and generate a polished multi-page PDF report with AI-written analysis, charts, and a custom cover page. Built by Deepanshu Garg.

## Features

- **CSV & Google Sheets import** ÔÇö Upload CSV files or connect Google Sheets with read-only OAuth authorization
- **AI-powered insights** ÔÇö AI Executive Summary, AI Insight Cards, Anomaly Detection using your choice of provider (Groq, OpenAI, Gemini, Claude, DeepSeek, Mistral, Together AI)
- **Custom branding** ÔÇö Add your logo, brand colours, custom fonts (Fraunces + IBM Plex), and a cover letter
- **16 chart types** ÔÇö Bar, line, pie, area, donut, scatter, bubble, heatmap, radar, treemap, funnel, waterfall, gauge, and more; auto-detect column types
- **PDF export** ÔÇö Download generated reports as polished PDFs (Pro tier removes Naxely watermark)
- **Shareable links** ÔÇö Share reports via a public link with optional expiry date
- **Scheduled reports** ÔÇö Upload data once and schedule recurring report generation (Pro and Agency tiers)
- **PowerPoint export** ÔÇö Export reports as .pptx files (Agency tier)
- **Full white-label** ÔÇö Agency-tier reports carry no Naxely branding at all
- **Programmatic API** ÔÇö Agency-tier API access for automated report generation
- **Dark mode** ÔÇö The app supports a dark mode UI
